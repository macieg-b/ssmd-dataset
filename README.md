# SSMD – SMS Stealing Malware Dataset

The **SSMD (SMS Stealing Malware Dataset)** is a curated collection of Android malware samples designed for research on **SMS interception and OTP-related threats**.

---

## 📄 About the Dataset

The dataset supports research in the area of:
- SMS interception malware  
- OTP-stealing attacks  
- Mobile security and Android threat analysis  

---

## 🔐 Dataset Access

Access to the dataset is granted **for academic and research purposes only**.

To request access, please complete the form available on the project website:

👉 https://macieg-b.github.io/ssmd-dataset/

After verification and approval, the dataset (package names and SHA-256 hashes in CSV format) will be provided via e-mail.
